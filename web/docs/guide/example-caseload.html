Example caseload

This page sets out one small, invented CoCM caseload. Every metric page from metric 1 to metric 8 uses it. Each page uses the part of the data it needs, so the eight results below all come from the same patients.

Reporting month: March 2025. The metric 8 review window is 31 January to 31 March.

The same patients are test data in tests/fixtures/example-caseload, in the format the data contract sets out, with the expected results in expected.toml. Any tool that calculates the metrics should reproduce the results below from it.
